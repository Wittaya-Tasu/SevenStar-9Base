# SevenStar-9Base

## รุ่นปัจจุบัน V1.4 — รายชื่ออาชีพครบ 7 ดาว

- รวบรวมจากภาพของผู้ใช้ครบดาว 1–7 ย่อและรวมคำใกล้เคียงภายในแต่ละดาว
- กดแสดงอาชีพ/ซ่อนอาชีพใต้เลขดาวแต่ละดวง เริ่มต้นซ่อน จัดชิดซ้าย 2 คอลัมน์; มือถือจอแคบ 1 คอลัมน์
- PNG/PDF รวมเฉพาะรายการอาชีพที่เปิดไว้ตอนบันทึก พร้อมสี ดอกจัน และไฮไลท์เดิม
- รายการรวมอยู่ใน `docs/OCCUPATIONS.md`; ข้อมูลใช้แสดงใน `js/occupation-data.js`
- แชร์ลูกโซ่จากต้นฉบับดาว4 แยกไว้เป็นข้อมูลรอทบทวน ไม่แสดงเป็นอาชีพแนะนำและไม่รวมกับขายตรง
- อัปโหลดไฟล์ภายใน ZIP ทับราก Repository เดิม แล้วรีเฟรช Ctrl+F5 ให้เห็นรุ่น 1.4
- กฎคะแนน ลำดับดาว และปฏิทินเดิมไม่เปลี่ยน

- อัปโหลดไฟล์ใน ZIP ทับราก Repository เดิม แล้วกด Ctrl+F5 ควรเห็นรุ่นทดสอบ 1.3
- ทดสอบกฎ 8 กรณี รหัสตั้งต้นครบ 343 แบบ การ์ดและการส่งออกด้วยชุดทดสอบ Node; ยังไม่ได้ทดสอบหน้าตาและการกดดาวน์โหลดในเบราว์เซอร์จริงสำหรับรุ่นนี้

## V1.2 — กฎคะแนน 2.0 (ยังใช้กับ 23 หัวข้อเดิม)

- Dropdown 23 หัวข้อ 6 หมวดตาม `หัวข้อ และ ภพ.xlsx` ใช้รายการภพล่าสุด ไม่ใช้รายการเก่าด้านล่าง
- ประเมิน 5 ปัจจัยเต็ม 100 ไม่มีโบนัส; น้ำหนักกลุ่ม 100 หรือ 80/20 หรือ 70/20/10
- เพิ่มเพศเจ้าชะตา: ชาย/หญิง/ยังไม่ระบุ ใช้แยกภพรองเรื่องคู่ครอง และบันทึกพร้อม Favorite
- ภพหลักน้ำเงินเข้ม ภพรองเขียว ภพเสริมเขียวอ่อน; ตำแหน่งซ้ำใช้สีหลักก่อนรองก่อนเสริม แต่คิดคะแนนครบทุกกลุ่ม
- ยังคลิกได้ 7 ชุดแบบสองทิศทาง; สีจากการคลิกอยู่เหนือสีภพ แต่แถบล่างคงบอกกลุ่มภพ
- PNG/PDF รวมแผนผัง สีทั้งหมด เพศ และการ์ดคะแนน พร้อมขยายความสูงตามรายละเอียด
- ใช้ Calendar Engine 1.0 เดิม ไม่ได้สลับเป็น Candidate 1.1
- กฎฉบับใช้งานและตารางภพทั้งหมด: `docs/SCORING_RULES.md` ส่วนข้อมูลรุ่นก่อนด้านล่างเป็นประวัติ ไม่ใช่เกณฑ์ปัจจุบัน

### อัปเดตระบบที่มีอยู่

สำรอง Repository เดิม แตก ZIP แล้วอัปโหลดไฟล์และโฟลเดอร์ภายในไปทับที่ราก Repository เดิม (ระดับเดียวกับ index.html) ไม่ต้องสร้าง Repository ใหม่
รอ GitHub Pages อัปเดตแล้วกด Ctrl+F5 ควรเห็นรุ่นทดสอบ 1.2 รายการโปรดยังคงอยู่เมื่อใช้ URL และเบราว์เซอร์เดิม
รายการโปรดเก่าที่ไม่มีเพศจะไม่ถูกเดาเพศ กรุณาเลือกเมื่อประเมินคู่ครอง

### การตรวจสอบ

ตรวจ 343 รหัส × 23 หัวข้อ × 2 เพศ = 15,778 กรณี รวมกฎลดระดับ การซ้ำข้ามกลุ่ม และขอบเขตคะแนน
ทดสอบปฏิทิน การสร้างแผนผัง การคลิก และเส้นทางวาดไฟล์ส่งออกผ่านชุดทดสอบ Node แล้ว
ยังไม่ได้ทดสอบการกดดาวน์โหลดและหน้าตาในเบราว์เซอร์จริงสำหรับรุ่นนี้ กรุณาทดลอง PNG/PDF กับหัวข้อที่มีหลายภพ เช่น การเรียน

## ประวัติรุ่นก่อน (กฎคะแนนเก่าถูกแทนที่แล้ว)

WebApp รุ่นทดสอบสำหรับสร้างแผนผังดวงเดิม “เลข 7 ตัว 9 ฐาน” จากวัน เดือน ปี พ.ศ. และเวลาเกิด

## ขอบเขตรุ่น 0.8

- ปรับวันที่โหราศาสตร์: เวลา 00:00–05:59 น. ย้อนวันทั้งชุด 1 วัน
- แปลงวันสุริยคติเป็นเดือนจันทรคติจาก Dataset ภายใน Repository
- ปีนักษัตรเปลี่ยนที่ขึ้น 1 ค่ำ เดือน 5
- สร้างฐาน 1–9
- ฐาน 4 แสดงผลรวมด้านบนและชื่อผลลัพธ์ด้านล่าง
- แสดงชื่อความสัมพันธ์ระหว่างฐาน 3 และฐาน 4 ด้วยสีและน้ำหนักตัวอักษรตามกฎ
- คลิกช่องเพื่อดูรายละเอียดและไฮไลท์เลขเดียวกัน
- เลือกแสดงอายุเต็มหรืออายุย่าง
- บันทึก Favorite ในเบราว์เซอร์สำหรับการทดสอบ
- หน้าดวงจรแยกไว้ แต่ยังไม่คำนวณ
- ยกเลิกสัญลักษณ์และดาว 5 แฉกทุกสี
- แสดงชื่อความสัมพันธ์ระหว่างฐาน 3 และฐาน 4 ตามตารางคู่ดาวฉบับล่าสุด
- ตรวจเงื่อนไขเลขเชื่อมภพเสียจาก หินะ, อริ, มรณะ, พยายะ, อุบาทว์, มหาโจร และทาสาในฐาน 8
- คลิกฐาน 3 หรือฐาน 4 แล้วไฮไลท์เลขเดียวกัน พร้อมเชื่อมฐาน 3–4 ในแนวดิ่งทั้งสองทิศทาง
- เมื่อคลิกฐาน 4 ใช้เลขฐาน 3 ค้นหาช่องเชื่อมโยง ไม่ใช้เลขผลรวมฐาน 4 ค้นหาซ้ำ
- เพิ่มพื้นหลังเขียวอ่อนให้มิตรใหญ่ และพื้นหลังแดงอ่อนให้ศัตรูใหญ่
- บันทึกแผนผังดวงเป็น PNG หรือ PDF จากปุ่มข้าง “ล้างการเลือก”
- ลดความเด่นของชื่อฐาน และย่อฐาน 5–7 ให้เป็นข้อมูลรอง

## วิธีนำขึ้น GitHub Pages

1. สร้าง Repository ชื่อ `SevenStar-9Base`
2. อัปโหลดไฟล์และโฟลเดอร์ทั้งหมดจาก ZIP ไปไว้ที่รากของ Repository
3. เปิด `Settings → Pages`
4. เลือก `Deploy from a branch`
5. เลือก Branch `main` และ Folder `/ (root)`
6. บันทึกและรอ GitHub สร้าง URL

URL จะมีรูปแบบ:

```text
https://<ชื่อผู้ใช้>.github.io/SevenStar-9Base/
```

| 22 เมษายน 2527 | 01:49 | เสาร์ · เดือน 5 · ปีชวด · เลขตั้งต้น `7,5,1` |



## ข้อจำกัดของรุ่นทดสอบ

- Dataset ปฏิทินครอบคลุมช่วงที่ UI อนุญาตประมาณ พ.ศ. 2469–2669 และมีข้อมูลเผื่อขอบเขต

- การกำหนดอธิกมาส/อธิกวารอาจต่างกันระหว่างตำราหรือสำนัก จึงต้องตรวจชุดวันที่สำคัญเพิ่มเติมก่อนประกาศเป็น Production
- Favorite ยังเก็บใน `localStorage` ของเครื่องทดสอบ ไม่ได้เชื่อม Google Sheet
- ยังไม่มีระบบดวงจรและกฎความสัมพันธ์ฐาน 3–4
