# SevenStar-9Base

WebApp รุ่นทดสอบสำหรับสร้างแผนผังดวงเดิม “เลข 7 ตัว 9 ฐาน” จากวัน เดือน ปี พ.ศ. และเวลาเกิด

## ขอบเขตรุ่น 0.5

- ปรับวันที่โหราศาสตร์: เวลา 00:00–05:59 น. ย้อนวันทั้งชุด 1 วัน
- แปลงวันสุริยคติเป็นเดือนจันทรคติจาก Dataset ภายใน Repository
- ปีนักษัตรเปลี่ยนที่ขึ้น 1 ค่ำ เดือน 5
- สร้างฐาน 1–9
- ฐาน 4 แสดงผลรวมด้านบนและชื่อผลลัพธ์ด้านล่าง
- แสดงชื่อความสัมพันธ์ระหว่างฐาน 3 และฐาน 4 ด้วยสีและน้ำหนักตัวอักษรตามกฎ
- คลิกช่องเพื่อดูรายละเอียดและไฮไลท์เลขเดียวกัน
- เลือกแสดงอายุเต็มหรืออายุย่าง
- บันทึก Favorite ในเบราว์เซอร์สำหรับการทดสอบ
- หน้าดวงจรแยกไว้ แต่ยังไม่คำนวณ
- ยกเลิกสัญลักษณ์และดาว 5 แฉกทุกสี
- แสดงชื่อความสัมพันธ์ระหว่างฐาน 3 และฐาน 4 ตามตารางคู่ดาวฉบับล่าสุด
- ตรวจเงื่อนไขเลขเชื่อมภพเสียจาก หินะ, อริ, มรณะ, พยายะ, อุบาทว์, มหาโจร และทาสาในฐาน 8
- คลิกฐาน 3 หรือฐาน 4 แล้วไฮไลท์เลขเดียวกัน พร้อมเชื่อมฐาน 3–4 ในแนวดิ่งทั้งสองทิศทาง
- เมื่อเชื่อมฐาน 4 กลับไปฐาน 3 ระบบไฮไลท์เลขของทั้งสองฝั่งทุกตำแหน่งในแผนผัง
- เพิ่มพื้นหลังเขียวอ่อนให้มิตรใหญ่ และพื้นหลังแดงอ่อนให้ศัตรูใหญ่
- ลดความเด่นของชื่อฐาน และย่อฐาน 5–7 ให้เป็นข้อมูลรอง

## Calendar Engine v1.1 Candidate

- เพิ่ม `js/thai-lunar-engine.js` เป็น Engine สูตรคณิตศาสตร์แบบไม่ต้องใช้ Dataset
- แก้รหัสเดือนภายใน `15 → เดือน 5` และ `16 → เดือน 6`
- ปีนักษัตรเปลี่ยนตั้งแต่ขึ้น 1 ค่ำ เดือน 5
- เพิ่ม API `thaiBirthDateTimeToLunar()` ซึ่งใช้กฎเวลา 06:00 น. และคืนเลขตั้งต้นทั้ง 3 ค่า
- WebApp ยังใช้ `js/calendar-engine.js` รุ่นเดิม เพื่อไม่ให้การเพิ่ม Candidate กระทบระบบที่ใช้งานได้แล้ว

## วิธีนำขึ้น GitHub Pages

1. สร้าง Repository ชื่อ `SevenStar-9Base`
2. อัปโหลดไฟล์และโฟลเดอร์ทั้งหมดจาก ZIP ไปไว้ที่รากของ Repository
3. เปิด `Settings → Pages`
4. เลือก `Deploy from a branch`
5. เลือก Branch `main` และ Folder `/ (root)`
6. บันทึกและรอ GitHub สร้าง URL

URL จะมีรูปแบบ:

```text
https://<ชื่อผู้ใช้>.github.io/SevenStar-9Base/
```

## ชุดทดสอบสำคัญ

| วันเกิดตามทะเบียน | เวลา | ผลที่ต้องได้ |
|---|---|---|
| 22 เมษายน 2527 | 01:49 | เสาร์ · เดือน 5 · ปีชวด · เลขตั้งต้น `7,5,1` |
| 22 เมษายน 2527 | 08:00 | อาทิตย์ · เดือน 5 · ปีชวด · เลขตั้งต้น `1,5,1` |

สำหรับ `7,5,1` ฐาน 4 ต้องเป็น:

```text
13, 9, 12, 8, 11, 14, 17
```

และฐาน 8–9 ต้องเป็น:

```text
ฐาน 8: 6, 4, 2, 7, 5, 3, 1
ฐาน 9: 6, 1, 3, 5, 7, 2, 4
```

## ข้อจำกัดของรุ่นทดสอบ

- Dataset ปฏิทินครอบคลุมช่วงที่ UI อนุญาตประมาณ พ.ศ. 2469–2669 และมีข้อมูลเผื่อขอบเขต
- Dataset สร้างจากโครงการ `hmmbug/pythaidate` แล้วตรวจ Golden Test ของโปรเจกต์
- การกำหนดอธิกมาส/อธิกวารอาจต่างกันระหว่างตำราหรือสำนัก จึงต้องตรวจชุดวันที่สำคัญเพิ่มเติมก่อนประกาศเป็น Production
- Favorite ยังเก็บใน `localStorage` ของเครื่องทดสอบ ไม่ได้เชื่อม Google Sheet
- ยังไม่มีระบบดวงจรและกฎความสัมพันธ์ฐาน 3–4
