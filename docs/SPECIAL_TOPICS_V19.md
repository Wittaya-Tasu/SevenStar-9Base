## 2001 ดวงบุญ-บาป
นับแยก 4 ตำแหน่ง: อัตตะฐาน1 ตะนุฐาน2 พันธุฐาน2 สุภะฐาน3
บุญ = ไม่เชื่อมภพเสีย; บาป = เชื่อมภพเสีย ตามเลขดาวตรงกันรวมตัวเอง
4/3/2/1 ข้อ = มหาลัย/มัธยม/ประถม/อนุบาล; 0 ข้อ = ไม่เข้าเกณฑ์
สีบุญ: ทอง/น้ำเงิน/เขียว/น้ำเงินอ่อน สีบาป: แดงเข้ม/แดงอ่อน/ขาวดำ/เทา
ไม่ใช้เงื่อนไขคู่สัมพันธ์เพื่อเลื่อนระดับ และไม่แบ่งภพเสียหลักรองเพื่อเลื่อนระดับอีก
หัวการ์ด เช่น ดวงบุญ : มหาลัย แสดงสองการ์ดเสมอ
รายการไม่ผ่านแสดงขีด - รายละเอียดแสดงเฉพาะภพที่ผ่าน บุญน้ำเงิน บาปแดง ไม่แสดงเลขฐานหรือข้อมูลว่าง

## 2006 อายุคู่ครอง
ปัตนิอยู่ฐาน2ช่อง7 หาฐาน4จากดาวเดียวกันในฐาน3
อายุมากกว่า: ดาวตรงปิตา/มาตา/มัชฌิมาฐาน1 หรือผลรวมฐาน4ตรงเลขกำลังของดาวตำแหน่งเหล่านี้
อายุน้อยกว่า: ดาวตรงทาสา/ทาสีฐาน3 หรือผลรวมตรงเลขกำลังของปุตตะฐาน2/ทาสา/ทาสีฐาน3
อายุใกล้เคียง: ดาวตรงอัตตะฐาน1 หรือผลรวมตรงเลขกำลังอัตตะฐาน1/ตะนุฐาน2
เลขกำลัง: 1=6, 2=15, 3=8, 4=17, 5=19, 6=21, 7=10 หรือ20
แต่ละกลุ่มใช้ OR แสดงทุกกลุ่มที่ผ่าน ไม่มีการเลือกลำดับความสำคัญ หากไม่ผ่านเลยแสดงไม่เข้าเกณฑ์

## 2016 ความรัก-ชีวิตคู่
ลบ 1008/1009/1010 จากรายการเลือก แต่คงสูตรภายในเพื่อใช้สามการ์ด:
1. ความรัก ใช้สูตร1008
2. คู่ครอง ใช้สูตร1009เมื่อชาย/1010เมื่อหญิง ชื่อการ์ดตามเพศ
3. ชีวิตคู่ ใช้ช่อง7ฐาน1,2,3 จับคู่ตามลำดับ (1,2),(1,3),(2,3)
ใช้ตารางคู่เลขที่ผู้ใช้ให้ตามทิศทางเดิม ไม่กลับคู่หรือแปลงตัวเลขตัวที่สองเป็นเลขกำลัง
คู่เงื่อนไขพิเศษตรวจ getRelations(เลขแรก,เลขที่สอง,ชุดเลขภพเสีย) ของระบบเดิม เพื่อเปลี่ยนชื่อเมื่อมีศัตรู/ศัตรูใหญ่
คู่ดีสีเขียวเข้มหนา คู่ไม่ดีสีแดงเข้ม
จำนวนคู่ดี 3/2/1/0 = การ์ดทอง/เขียว/ขาวดำ/แดงเข้ม
