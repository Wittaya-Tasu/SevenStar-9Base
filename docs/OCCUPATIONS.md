## รายชื่ออาชีพฉบับรวม

### ดาว 1

ราชการ / รัฐวิสาหกิจ　 พนักงานบริษัทและห้างร้านใหญ่　 นักการเมือง　 ร้านทอง　 งานการไฟฟ้า / ช่างไฟฟ้า　 เครื่องใช้ไฟฟ้า โคมไฟและหลอดไฟ　 ธุรกิจตู้เกม　 คอมพิวเตอร์และอินเทอร์เน็ต　 เจ้าของกิจการขนาดใหญ่　 เพชรพลอย / อัญมณี　 ธุรกิจพลังงาน

### ดาว 2

### ดาว 3

ทหาร / ตำรวจ　 วิศวกร　 ศัลยแพทย์ / แพทย์ฝังเข็ม　 ทันตแพทย์　 งานช่างโลหะ ช่างไม้และช่างสำรวจ　 นักเคมี / ผลิตเคมีภัณฑ์　 นักวิทยาศาสตร์　 ร้านอาวุธ　 นักกีฬา / อุปกรณ์กีฬา / ฟิตเนส　 เครื่องจักร / ช่างกล　 ขายรถยนต์และธุรกิจยานยนต์　 ศุลกากร　 อัยการ　 พัศดี　 ค้าอะไหล่　 โรงฆ่าสัตว์　 โรงกลึงเหล็ก / ค้าโลหะ　 จักรยานและจักรยานยนต์　 นักบิน　 ธุรกิจรถตู้　 คาร์แคร์ / ตรวจสภาพรถเอกชน　 ธุรกิจสายพาน　 ช่างฝีมือ / ช่างเทคนิค　 เครื่องมือเหล็กและของมีคม　 งานต่อสู้ / เสี่ยงภัย / ผจญภัย　 งานประหารตามหน้าที่

### ดาว 4

### ดาว 5

### ดาว 6
