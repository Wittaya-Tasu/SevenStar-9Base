รายการโปรดเก่าที่ไม่มีเพศจะไม่ถูกเดาเพศ กรุณาเลือกเมื่อประเมินคู่ครอง

- คลิกฐาน 3 หรือฐาน 4 แล้วไฮไลท์เลขเดียวกัน พร้อมเชื่อมฐาน 3–4 ในแนวดิ่งทั้งสองทิศทาง
- เมื่อคลิกฐาน 4 ใช้เลขฐาน 3 ค้นหาช่องเชื่อมโยง ไม่ใช้เลขผลรวมฐาน 4 ค้นหาซ้ำ
- เพิ่มพื้นหลังเขียวอ่อนให้มิตรใหญ่ และพื้นหลังแดงอ่อนให้ศัตรูใหญ่
- บันทึกแผนผังดวงเป็น PNG หรือ PDF จากปุ่มข้าง “ล้างการเลือก”
- ลดความเด่นของชื่อฐาน และย่อฐาน 5–7 ให้เป็นข้อมูลรอง
